---
name: oversikt
description: Oversikten over hvem som har hytta de neste fire ukene, as text in Norwegian to paste into an e-mail. Use when someone asks for the overview, the Friday e-mail, or who has the cabin in the coming weeks.
allowed-tools: Bash(node overview.js)
---

Run `node overview.js` from the project root. It reads the book as it is now and prints the overview.

Its output is the answer. Give it whole and unchanged in one code block, so it can be pasted into an e-mail: the weeks and dates in it follow the cabin-week rule.

If the command fails, pass on what it said.
